# JollyIT website

Source for the JollyIT website. Plain static site: HTML, CSS, and a little JavaScript, no build step.

## Layout

- `index.html` — landing page
- `assets/css/site.css` — styles
- `assets/img/` — images and logo

## Local preview

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080.
